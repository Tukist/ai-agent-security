基于五篇论文的智能体安全攻防总结报告

摘要聚焦提示注入、间接提示注入、工具调用安全、推理劫持和运行时防御，并补充 2024-2026 年的联网技术动态。

一句话结论

智能体安全的核心已经从“模型是否输出有害文本”转向“模型是否会在不可信上下文影响下执行错误工具动作”。可靠防线需要协议隔离、任务一致性、权限最小化、运行时监控、动态红队和持续修补共同作用。

本地 5 篇现在均为 agent/LLM 安全相关论文；此前误下的高能物理论文已从报告主轴中替换为 AgentDojo。

五篇论文如何串起来

Tensor Trust [P1]

把提示注入攻防数据化：126k+ 攻击、46k+ 防御，区分 prompt hijacking 与 prompt extraction。

StruQ [P2]

用结构化查询隔离 prompt/data，并通过微调让模型忽略 data 通道中的恶意指令。

MELON [P3]

针对工具型 agent 的 IPI，遮蔽用户任务并重执行，比较工具动作是否仍相似。

UDora [P4]

动态劫持 agent 自身 reasoning trace，诱导恶意行为或指定工具调用。

AgentDojo [P5]

构建动态工具型 agent 安全基准：70 个工具、97 个真实任务、27 个注入目标和 629 个安全测试。

技术路线地图

路线关键思想代表来源
基准与红队用真实/动态任务评估 ASR、UA、BU、风险意识和工具调用行为。[P1][P5][P4][W5][W6][W12]
协议隔离把可信指令和不可信数据分成不同通道，避免混在一个 prompt 里。[P2][W14]
运行时检测通过遮蔽、重执行、因果归因或工具动作比较判断是否被恶意数据支配。[P3][W13]
任务一致性工具调用必须与用户原始任务一致，而不是只看文本是否可疑。[W7][W11]
记忆/RAG 防护长期记忆和知识库可被污染，需要来源认证、写入审批和检索隔离。[W8]
