AI Agent 红队 / 推理劫持攻击

UDora：通过动态劫持推理红队测试 LLM 智能体

UDora 针对会规划和调用工具的 LLM 智能体，动态生成并扰动其推理轨迹，在最优插入点注入目标扰动，从而诱导恶意工具调用或目标行为。

核心创新

动态推理劫持

先生成任务推理 trace，再自动识别插入扰动的最佳位置，使攻击顺着智能体自己的推理链推进。

统一红队框架

同时覆盖 malicious environment 与 malicious target tool 两类场景，能诱导指定恶意行为或指定工具调用。

迭代优化

把扰动后的推理作为 surrogate response 进行优化，逐步提高目标攻击成功率。

技术路线

  1. 生成推理轨迹

    对给定任务获取 agent 的 reasoning trace，显式暴露规划过程。

  2. 定位插入点

    搜索 trace 中最适合注入目标扰动的位置，减少对任务表层文本的粗暴改写。

  3. 优化扰动

    迭代构造 UDora string，使 agent 的后续推理逐步转向攻击目标。

  4. 跨数据集评估

    在 InjecAgent、WebShop、AgentHarm 等数据集上比较 ASR。

关键指标

数据集代表性结果
InjecAgent平均 ASR 可达 99%（LLaMA 3.1）和 97%（另一主模型设置）。
WebShop平均 ASR 达 61.75%（LLaMA 3.1）与 91.50%（另一主模型设置）。
AgentHarm在 LLaMA 3.1 上 ASR 达 97.7%，在另一主模型设置上达 100.0%。
真实案例论文展示 AutoGen 邮件智能体被诱导抓取并回复最近邮件内容的隐私窃取示例。

研究亮点

  • 攻击对象从单轮 LLM 输出扩展到带工具调用的多步 agent 行为。
  • 利用 reasoning trace 本身作为攻击面，解释了为什么直接攻击有时失败而推理劫持能成功。
  • 跨多个 agent 数据集和攻击类别取得高 ASR，适合作为防御方法的压力测试基准。
