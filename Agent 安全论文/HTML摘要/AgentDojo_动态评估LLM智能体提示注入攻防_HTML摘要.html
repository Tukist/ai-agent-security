AgentDojo：评估 LLM 智能体提示注入攻防的动态环境

论文提出 AgentDojo，一个面向工具型 LLM 智能体的动态评估框架，用于衡量智能体在不可信工具数据和提示注入攻击下的任务效用与安全鲁棒性。

核心创新

动态 benchmark

AgentDojo 不是静态测试集，而是可扩展环境，可持续加入新任务、防御和自适应攻击。

工具型 agent 场景

覆盖邮箱、日历、云盘、Slack、旅行预订、银行等真实任务，将风险从文本输出推进到工具调用行为。

显式效用与安全检查

用环境状态上的确定性 utility/security 函数评估任务完成和攻击成功，避免让 LLM judge 被提示注入本身影响。

技术路线

  1. 定义环境

    为每个 task suite 建模状态、工具和工具调用副作用，让 agent 在可控环境中执行任务。

  2. 定义用户任务

    为真实用户目标编写任务描述与 deterministic utility function，衡量无攻击或受攻击时是否完成任务。

  3. 定义注入任务

    为攻击者目标指定 injection endpoint 与 security function，检测数据泄露、越权动作等安全失败。

  4. 评估攻防组合

    在多个 LLM agent、提示注入攻击、攻击者知识水平和防御范式下报告 benign utility、utility under attack 与 targeted ASR。

关键指标

指标结果/含义
基准规模包含 70 个工具、97 个真实用户任务、27 个注入目标和 629 个安全测试用例。
模型效用当前 LLM 在无攻击情况下完成 AgentDojo 任务的比例低于 66%，说明真实工具型任务本身已有难度。
攻击成功现有提示注入攻击在最佳 agent 上 targeted ASR 低于 25%，可破坏部分安全属性但无法全面突破。
防御效果部署二级攻击检测器等现有防御后，攻击成功率可降至约 8%，但效用和鲁棒性仍存在权衡。
攻击面差异不同 task suite 难度差异明显，例如 Slack 场景攻击成功率可达约 92%，而部分异常敏感目标几乎无法成功。

研究亮点

  • 把 agent 安全评估从单轮 prompt/jailbreak 推进到多步工具调用环境。
  • 强调 benchmark 必须支持自适应攻击，否则容易高估针对固定攻击的防御。
  • 为后续 MELON 等防御论文提供了重要评估基准和任务语境。
