AI Agent 安全 / 间接提示注入防御

MELON：AI 智能体间接提示注入的可证明防御

MELON 利用“成功攻击会让智能体下一步动作更依赖恶意任务而非用户任务”的观察，通过遮蔽用户提示并重执行轨迹来检测间接提示注入。

核心创新

Masked re-Execution

把用户任务经过 masking function 改写后重新执行，如果原执行和遮蔽执行产生相似工具动作，则判定可能被恶意任务主导。

Tool comparisON

比较两条轨迹中的工具调用相似度，而不是只做文本分类，贴合 agent 攻击的实际危害出口。

可组合防御

MELON 可与提示增强防御组合为 MELON-Aug，进一步降低 ASR 并保持正常效用。

技术路线

  1. 原始执行

    智能体按用户任务和工具返回信息生成下一步动作。

  2. 遮蔽执行

    对用户任务做 masking 后重放同一轨迹上下文，观察下一步动作是否仍相似。

  3. 相似度判定

    若两次生成的工具动作高度相似，说明动作可能由工具返回中的恶意任务驱动。

  4. 误报/漏报控制

    论文加入三项关键设计以降低 false positive 和 false negative，并通过消融实验验证。

关键指标

指标结果
数据集与模型在 AgentDojo 上评估 GPT-4o、o3-mini、Llama-3.3-70B。
GPT-4o 总体MELON-Aug 达到 68.72% Utility under Attack 与 0.32% ASR；无防御为 69.08% UA 与 16.06% ASR。
最低 ASRMELON 平均 ASR 可到 0.24%；MELON-Aug 为 0.32%。
效用保持相比 LLM detector 等检测式防御，MELON 避免了简单拒绝导致的 0 UA 问题，同时显著降低攻击成功率。

研究亮点

  • 把间接提示注入检测转化为“用户任务依赖性”检验，思路简洁且贴近 agent 行为。
  • 在攻击阻断和效用保持之间取得比多种 SOTA baseline 更好的折中。
  • 提供理论证明、主实验、组合防御和消融，证据链完整。
