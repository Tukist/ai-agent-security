LLM 安全 / 提示注入数据集

Tensor Trust：来自在线游戏的可解释提示注入攻击

论文通过一个公开在线攻防游戏收集真实人类攻击与防御样本，构建提示劫持和提示提取鲁棒性基准，用于研究指令跟随 LLM 的提示注入脆弱性。

核心创新

真实人类攻防数据

利用 Tensor Trust 游戏收集超过 126,000 条提示注入攻击与 46,000 条基于提示的防御。

可解释攻击策略

通过聚类与人工标注总结 16 类高频攻击策略，显示攻击往往具有组合式结构并会在玩家之间传播演化。

双任务基准

将提示注入拆为 prompt hijacking 与 prompt extraction，分别评估模型是否会被改写目标或泄露防御提示/访问码。

技术路线

  1. 游戏化采集

    玩家编写防御提示，使模型仅在输入秘密访问码时输出 “access granted”；攻击者不知道防御和访问码，需要注入提示绕过。

  2. 启发式筛选

    从成功攻击中区分提示劫持与提示提取，去除偶然命中和不符合任务定义的样本。

  3. 策略分析

    用 LDA 聚类和人工审阅识别主导攻击策略，并分析 9 周内策略频率变化。

  4. 鲁棒性评估

    在多种 LLM 上测试 hijacking robustness rate 与 extraction robustness rate，并额外发布提示提取检测数据集。

关键指标

指标数值/结论
数据规模126k+ 攻击，46k+ 防御；作者称其为当时最大的人类生成指令跟随 LLM 对抗样本集。
任务类型提示劫持：不用访问码也诱导输出 access granted；提示提取：诱导模型泄露足够防御信息以获得访问码。
检测样本零样本提示提取检测可达到约 97% precision 和 84% recall，但作者指出鲁棒检测仍未解决。
泛化性部分游戏内攻击策略可迁移到真实部署的 LLM 应用，说明游戏约束下学到的策略具有外部有效性。

研究亮点

  • 把提示注入从抽象漏洞变成可重复、可统计、可解释的攻防生态。
  • 强调攻击不是单一 “ignore previous instructions”，而是多策略组合与社会传播。
  • 提供数据、代码和基准，便于后续防御方法做横向比较。
